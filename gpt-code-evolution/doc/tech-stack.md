# Stack

- **Language.** TypeScript.
- **UI.** Vue; Vite for build/dev server.
- **State.** bitECS.
- **Graphics.** PixiJS.
- **Tests.** Vitest for isolated checks; Playwright for browser acceptance.
- **Versions.** package-lock.json is authoritative; inspect installed APIs before changes.
