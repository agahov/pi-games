# Documentation

- **Format.** `- **Short title.** Details.` One point per item.
- **Content.** Keep project-specific intent, decisions, trade-offs, and constraints. Remove obvious advice and code paraphrases.
- **Maps.** Show boundaries and relationships. Link implementation details.
- **Ownership.** Link the canonical document; do not duplicate it.
- **Accuracy.** Separate proposals from implemented behavior. Preserve task evidence and acceptance criteria.
