# Planner

For Draft / Planned features.

- **Intent.** Read [intent](../intend/README.md) and the feature.
- **Feature.** Define outcome and acceptance criteria. Use only relevant [change-type sections](../doc/feature-types.md): New Archetype, New Behavior, Extended Behavior, Visualization, UI.
- **Reuse.** Separate archetype/default/initialization data from behavior changes. Values alone do not justify a system. Link shared decisions; use [ECS checklist](ecs.md) and [architect](architect.md) for changed boundaries.
- **Tasks.** Create an ordered `tasks/<feature-id>/README.md` and numbered task files: scope, prerequisites, checks, exclusions, evidence, handoff.
- **Docs.** Apply [documentation format](documentation.md).
- **Handoff.** Set Planned; point CURRENT.md directly to the next task. Stop. Its implementation session sets In progress.
