# Intent summary

Build a small 2D web-game foundation with Vue, TypeScript, Vite, PixiJS, bitECS, Vitest, and Playwright. Keep game state and systems independent from UI and rendering; document boundaries, test general systems in isolation, and evolve the workflow through evidence-based implementation, review, demo, and reusable reflection.

The first vertical slice is one static square: 64×64 world units at the origin, presented in an 800×600 (4:3) logical area with uniform scaling and letterboxing. The raw source remains in [`INTEND.md`](INTEND.md).
